{% comment %} SKU Details section, shared by Add New Product and Add Existing Product. Two levels of button, deliberately: * "Save SKU" sits inside a SKU's own boundary and commits that SKU within the form - it folds the block into a summary line and opens the next blank one. Nothing is sent to the server. * the page's own Save button, outside this card, submits everything. Requires in context: sku_form_fields, sku_fields, qty_name. IMPORTANT for anyone restyling this file: _sku_section_js.html clones the first .sku-block to create new ones, and its click handler tests `e.target.classList.contains(...)`. So: * keep the classes sku-block / sku-label / sku-saved / sku-edit / sku-summary / sku-body / save-sku / remove-sku and the d-none toggles; * keep the action buttons text-only - an icon inside one would become the event target and the handler would never fire. {% endcomment %}
